Sitio web portafolio desarrollado bajo la línea de diseño **Neobrutalista** (bordes marcados, contraste elevado y sombras sólidas)[cite: 5]. Construido como parte de la formación en el programa **Análisis y Desarrollo de Software (ADSO)** del SENA.

---

## 📌 Características Técnicas

- **Maquetación Semántica:** Estructura limpia basada en etiquetas de bloque (`<div>`) y elementos de HTML5[cite: 10].
- **Diseño Bi-dimensional con CSS Grid:** Organización eficiente de la formación académica, certificaciones y tarjetas de contacto[cite: 10, 11].
- **Flexibilidad con Flexbox:** Menú de navegación accesible, distribución de píldoras del stack tecnológico y centrado responsivo[cite: 10, 11].
- **100% Responsivo:** Adaptación completa a dispositivos móviles, tablets y escritorios mediante Media Queries y `auto-fit` dinámico[cite: 11].
